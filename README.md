# Nara | Symphony, Strength & Soul 🎻⚡🌿

> **La Sinfonía de tu Cuerpo, Mente y Alma.**
> Una landing page premium, cálida, inspiradora y de estética cinematográfica para la marca personal holística de Nara: chelista sinfónica profesional, entrenadora de fitness y coach de bienestar emocional.

---

## 🌟 Características de la Aplicación

- **Estética Hygge & Cinematic Shifting:** Alternancia elegante y orgánica de secciones en lino claro (`#F9F6F0`) y secciones de gran impacto en carbón nocturno (`#1A1A1A`) y dorado ámbar.
- **Ecualizador y Reproductor de Audio Flotante:** Un reproductor musical minimalista integrado que reproduce localmente la *Cello Suite No. 1 de Bach* interpretada en violonchelo por Nara, sincronizado con un ecualizador interactivo.
- **Internacionalización Dinámica (i18n):** Traducción en tiempo real (sin recarga de página para no interrumpir la música) disponible en **Español, Inglés, Alemán, Francés y Portugués** con persistencia de selección en `localStorage`.
- **4 Pilares del Bienestar:** Grid interactivo que describe los enfoques de Fitness Postural, Nutrición, Crecimiento Emocional y Lifestyle Hygge.
- **Captura de Leads de Alta Conversión:** Formulario diseñado con estética de sobre postal clásico que recopila de manera directa los objetivos de las potenciales clientas.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Semántica limpia e internacionalización nativa mediante atributos `data-i18n`).
- **CSS3 Vanilla** (Uso de variables personalizadas, efectos de desenfoque *backdrop-filter*, gradientes dorados y micro-interacciones de hover).
- **JavaScript ES6** (Lógica de reproducción multimedia, cambio de idiomas en vivo, persistencia y animaciones de scroll mediante *IntersectionObserver*).

## 🚀 Despliegue en GitHub Pages (¡En 1 Minuto!)

Para publicar esta página web en directo y de forma gratuita usando GitHub Pages, sigue estos pasos:

1. Entra a tu repositorio en GitHub: [github.com/abelruizrodes-pixel/nara](https://github.com/abelruizrodes-pixel/nara).
2. Ve a la pestaña **Settings** (Configuración) en la barra superior.
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En la sección **Build and deployment**:
   - **Source:** Selecciona *Deploy from a branch*.
   - **Branch:** Elige `main` y selecciona la carpeta `/ (root)`.
5. Haz clic en **Save** (Guardar).

¡Listo! En menos de un minuto tu página web estará publicada en:
👉 `https://abelruizrodes-pixel.github.io/nara/`

## 💻 Desarrollo Local

Para correr el proyecto localmente y realizar cambios:

```bash
# Clonar el repositorio
git clone git@github.com:abelruizrodes-pixel/nara.git

# Entrar al directorio
cd nara

# Iniciar un servidor local (ejemplo con Python)
python3 -m http.server 8200
```
Abre tu navegador en `http://localhost:8200` y disfruta de la experiencia.
